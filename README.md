# 🤖 بوت مركز الطحان

بوت تيليغرام لمساعدة طلاب 중심 الطحان: اختبار البوصلة، حاسبة المفاضلة 2025،
مقارنة التخصصين، الدورات المجانية، الجامعة الافتراضية، التعليم المفتوح،
الأسئلة الشائعة، والمساعد الذكي.

المحتوى مطابق لموقع [altahhan.vercel.app](https://altahhan.vercel.app).

## 1) التشغيل السريع

```bash
npm install
copy .env.example .env      # على ويندوز
# cp .env.example .env      # على لينكس/ماك
```

ثم افتح `.env` وضع `BOT_TOKEN`، وشغّل:

```bash
npm start
```

> يعمل البوت محلياً بـ **polling** مباشرة. في النشر على Render يتحول تلقائياً إلى **webhook**.

## 2) إعداد توكن تيليغرام

1. افتح [@BotFather](https://t.me/BotFather).
2. أرسل `/newbot`.
3. اختر اسماً للبوت ينتهي بكلمة `bot` (مثال: `altahan_center_bot`).
4. انسخ **التوكن** الذي يعطيك إياه، ويبدو هكذا:
   ```
   7123456789:AAExaMpleTokenValue...
   ```
5. ضعه في `.env`:
   ```
   BOT_TOKEN=7123456789:AAExaMpleTokenValue...
   ```

## 3) متغيرات البيئة

كل المتغيرات في `.env.example`. الإلزامي منها واحد فقط.

| المتغير | إلزامي | الوصف |
|---|---|---|
| `BOT_TOKEN` | ✅ | توكن البوت من @BotFather |
| `WHATSAPP_NUMBER` | ❌ | رقم واتساب بصيغة دولية (افتراضي `963999278956`) |
| `AI_API_KEY` | ❌ | مفتاح الذكاء الاصطناعي — بدونه يعمل محرك محلي |
| `AI_BASE_URL` | ❌ | عنوان الـ API (افتراضي `https://api.openai.com/v1`) |
| `AI_MODEL` | ❌ | الموديل (افتراضي `gpt-4o-mini`) |
| `AI_TIMEOUT_MS` | ❌ | مهلة الطلب (افتراضي `20000`) |
| `UPSTASH_REDIS_REST_URL` | ❌ | رابط Upstash Redis |
| `UPSTASH_REDIS_REST_TOKEN` | ❌ | توكن Upstash Redis |
| `TG_SUBS_KEY` | ❌ | مفتاح تخزين المشتركين |
| `TG_SENT_KEY` | ❌ | مفتاح آخر إعلان مُرسل |
| `ANNOUNCEMENT_URL` | ❌ | رابط جلب الإعلانات |
| `ANNOUNCE_POLL_MS` | ❌ | فترة الاستطلاع (الحد الأدنى دقيقة) |
| `PORT` | ❌ | منفذ الخادم |

**مهم:** البوت يعمل بكامل وظائفه بدون أي مفتاح اختياري —
الـAI يعود للمحرك المحلي والإشعارات تُحفظ في ذاكرة العملية فقط.

## 5) ما الذي يفعله البوت؟

### البوصلة
1. يسأل عن **فرعك** (علمي/أدبي/صناعي/تجاري/شرعي/فنون).
2. يسأل عن **معدله** (اختياري — يمكن تخطيه).
3. يعرض **10 أسئلة** باختيار من 4 إجابات.
4. يحسب النتيجة بنفس خوارزمية الموقع تماماً:
   - القطب المهيمن (طبي، هندسي، حاسوب، أعمال، إنسانيات) مع النسبة.
   - 3 أسباب لتبرير الاختيار.
   - التخصصات المتاحة لفرعه ومعدله مع حدود القبول 2025.
   - زر استشارة واتساب + زر إعادة الاختبار.

### حاسبة المفاضلة 2025
- حاسبة حقيقية بحدود القبول الرسمية.
- تقبل الأرقام العربية-الهندية (`٨٨٫٥`) والنصوص المختلطة (`معدلي 88.5`).
- سنة 2026 غير مفعلة بعد، وتعرض رسالة «قريباً» بدل بيانات وهمية.

### باقي الأقسام
- **مقارنة التخصصين** — بحث، ترشيح، صفحة نتائج مع زر swap.
- **الدورات المجانية** — 24 دورة مقسّمة بالفئات.
- **الجامعة الافتراضية** — 37 برنامجاً، مستويات، مقررات، مراكز.
- **التعليم المفتوح** — 7 جامعات، 8 تخصصات، الرسوم، شروط القبول.
- **الإنكليزية** — تقدير CEFR.
- **الأسئلة الشائعة والتواصل**.

## 6) المساعد الذكي

- **بدون `AI_API_KEY`** (الوضع الافتراضي): يعمل محرك محلي سريع بلا إنترنت،
  يغطي: أسئلة التسجيل، شروط القبول، مقارنة الأنظمة، ترشيح التخصص حسب الاهتمام،
  الدورات، أوقات الدوام، الخدمات الشريكة، وحساب المفاضلة.
- **مع `AI_API_KEY`**: يُرسل السؤال إلى مزوّد AI مع سياق محادثة محفوظ
  وحدود قصوى، ويُرجع رداً غنياً. عند فشل الطلب يعود للمحرك المحلي تلقائياً.

## 7) البث والإشعارات

- المشتركون يُحفظون في **مجموعة Redis** عبر Upstash (اختياري).
- يسحب البوت إعلانات الموقع من `ANNOUNCEMENT_URL` كل `ANNOUNCE_POLL_MS`.
- يرسل الإعلان الجديد لكل المشتركين مرة واحدة (منع التكرار عبر `TG_SENT_KEY`).
- **بدون Upstash** يعمل النظام بذاكرة العملية فقط — مناسب للتجربة،
  لكن الاشتراكات تُفقد عند إعادة التشغيل.

## 8) النشر على Render

المستودع مرتبط بـ Render عبر `render.yaml`. الخطوات:

1. ارفع المشروع إلى GitHub (بدون `node_modules` ولا `.env`).
2. في [render.com](https://render.com) أنشئ **Web Service** من المستودع.
3. أو اترك Render يقرأ `render.yaml` مباشرة (Blueprint).
4. أضف `BOT_TOKEN` في Environment.
5. انشر.

Render يضبط `RENDER_EXTERNAL_URL` تلقائياً، فيكتشف البوت وجوده ويشتغل بـ webhook
بدل polling، ويستخدم المسار `POST /webhook`.

## 9) بنية المشروع

```
tahan-bot/
├── bot.js              # نقطة الدخول: الأوامر، callbacks، الحالات
├── data.js             # مُصدِّر مركزي لكل البيانات
├── data/
│   ├── core.js         # البوصلة، المفاضلة، التواصل، الثوابت
│   ├── english.js      # تقدير CEFR
│   ├── courses.js      # الدورات المجانية
│   ├── virtual-u.js    # الجامعة الافتراضية
│   ├── compare.js      # بيانات المقارنة (108 تخصصاً)
│   ├── open-edu.js     # التعليم المفتوح
│   └── faq.js          # الأسئلة الشائعة
├── lib/
│   ├── sections.js     # كل الأقسام: مقارنة، دورات، VU، تعليم مفتوح
│   ├── ai.js           # المساعد الذكي (محلي + خارجي)
│   └── broadcast.js    # البث والإشعارات
├── mock-tg.mjs         # محاكي تيليغرام للاختبار
├── .env.example        # متغيرات البيئة
└── render.yaml         # إعدادات النشر
```

## 10) الأمان

- `.env` مُستثنى في `.gitignore` ولا يُرفع أبداً.
- لا يُطبع أي مفتاح في السجلات.
- `callback_data` كلها أقل من 64 بايت (حد تيليغرام).
- كل الرسائل محدودة بـ 4096 حرف (حد تيليغرام).
- الأخطاء في الإرسال لا تُسقط العملية.
