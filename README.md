# 🤖 بوت تيليغرام — مركز الطحان (بوصلة التخصص)

بوت تيليغرام يقدّم اختبار البوصلة (10 أسئلة) ويحدّد القطب الجامعي المناسب مع التخصصات المتاحة لفرع الطالب ومعدله، وتحويل مباشر للاستشارة الواتسابية.

## 1) إنشاء البوت والحصول على التوكن

1. افتح تيليغرام وابحث عن **@BotFather** (الحساب الرسمي لإنشاء البوتات).
2. أرسل الأمر: `/newbot`
3. أدخل اسماً للبوت (مثال: `مركز الطحان`) ثم اسماً مستخدماً ينتهي بـ `bot` (مثال: `altahan_center_bot`).
4. سيرسل لك BotFather **رمزاً طويلاً (token)** مثل:
   `7123456789:AAExaMpleTokenValue...`
5. انسخه فوراً — يظهر مرة واحدة فقط.

## 2) إعداد المشروع محلياً

1. انسخ ملف `.env.example` إلى `.env`:
   ```
   copy .env.example .env
   ```
2. افتح `.env` وضَع التوكن مكان `ضع_التوكن_هنا_من_BotFather`:
   ```
   BOT_TOKEN=7123456789:AAExaMpleTokenValue...
   ```
3. (اختياري) غيّر رقم الواتساب إن كان مختلفاً:
   ```
   WHATSAPP_NUMBER=963999278956
   ```

## 3) التشغيل

```
npm install
npm start
```

يجب أن ترى: `🤖 بوت مركز الطحان يعمل...`
افتح بوتك في تيليغرام واضغط `/start`.

> ⚠️ البوت يعمل فقط ما دام هذا الأمر شغالاً في الطرفية. أبقِ النافذة مفتوحة أو استخدم استضافة.

## 4) التشغيل الدائم (نشره على الإنترنت)

التشغيل من جهازك يتوقف عند إغلاقه أو انقطاع الكهرباء. خيارات النشر:

| الخيار | التكلفة | لمن؟ |
|---|---|---|
| **Render / Railway** (الأسهل) | مجاني بحدود استخدام | البداية |
| **VPS (Hetzner/DigitalOcean...)** | ~4-6$ شهرياً | تحمّل أعلى |
| **جهاز قديم/راسبيري باي** | مجاني | تشغيل منزلي دائم |

خطوات النشر على **Render** باختصار:
1. ارفع المجلد (بدون `node_modules`) إلى GitHub.
2. أنشئ حساباً على render.com → **New → Web Service**.
3. اربط المستودع، واجعل:
   - Build Command: `npm install`
   - Start Command: `node bot.js`
4. في قسم Environment أضف المتغيرين: `BOT_TOKEN` و `WHATSAPP_NUMBER`.
5. انشر — سيبقى البوت يعمل 24/7.

## 5) الأوامر

- `/start` — الصفحة الرئيسية
- `/quiz` — بدء اختبار البوصلة
- `/help` — المساعدة

## 6) ماذا يفعل البوت بالتفصيل؟

1. يسأل المستخدم عن **فرعه** (علمي/أدبي/صناعي/تجاري/شرعي/فنون).
2. يسأل عن **معدله** (اختياري — يمكن تخطيه).
3. يعرض **10 أسئلة** باختيار من 4 إجابات لكل سؤال.
4. يحسب النتيجة بنفس خوارزمية موقع `tahan-platform` تماماً:
   - القطب المهيمن (5 أقطاب: طبي، هندسي، حاسوب، أعمال، إنسانيات) مع النسبة.
   - لماذا هذا القطب (3 أسباب).
   - التخصصات المتاحة لفرعه ومعدله (محدودة بالقطبين الأعلى) مع حدود القبول 2025.
   - زر استشارة واتساب مجانية + زر إعادة الاختبار.

## 7) تخصيص سريع

- **تغيير أسئلة/بيانات**: عدّل ملف `data.js` (الأسئلة، الأوزان، التخصصات، الحدود).
- **تغيير النصوص**: كل النصوص في `bot.js`.
- **إضافة ميزات**: أخبرني وسأضيفها (إشعارات مفاضلة، حاسبة 2025، دعم لغات…).
